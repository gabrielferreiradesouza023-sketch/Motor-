# T-08: `sim/`
Fase: F1  |  Depende de: T-07
## Objetivo
`sim/`: simulador que gera snapshots e vendas para N ofertas × ângulos × criativos, com taxas "verdadeiras" plantadas (alguns vencedores, maioria perdedora, ruído realista).
## Arquivos
src/arb/sim/, tests/test_sim.py
## Critérios de aceite
Seeds repetíveis, vencedores plantados e ruído; snapshots e vendas válidos.
## Testes obrigatórios
Seeds repetíveis, vencedores plantados e ruído; snapshots e vendas válidos.
Qualidade: `uv run ruff check`, `uv run pytest`, `uv run arb doctor`.
