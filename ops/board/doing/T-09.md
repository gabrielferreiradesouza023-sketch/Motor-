# T-09: `arb sim run --seed X --budget 2400`
Fase: F1  |  Depende de: T-08
## Objetivo
`arb sim run --seed X --budget 2400`: roda o laboratório inteiro em simulação e mede `waste_ratio`, `cost_per_learning`, vencedores achados e vencedores mortos por engano.
## Arquivos
src/arb/sim/, src/arb/cli.py, tests/test_sim_lab.py
## Critérios de aceite
50 seeds: vencedor encontrado em ≥80%; waste_ratio médio <10%; calibração exige ADR.
## Testes obrigatórios
50 seeds: vencedor encontrado em ≥80%; waste_ratio médio <10%; calibração exige ADR.
Qualidade: `uv run ruff check`, `uv run pytest`, `uv run arb doctor`.
