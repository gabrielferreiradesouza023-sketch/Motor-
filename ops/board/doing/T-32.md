# T-32: Laboratório de sensibilidade das regras (grid de calibração)
Fase: F1+  |  Depende de: T-31
## Objetivo
Medir como os parâmetros de portão afetam acerto e desperdício nos perfis realistas, para o
humano decidir a calibração com dados — sem alterar `rules.yaml`.
## Arquivos
src/arb/sim/calibrate.py (novo), src/arb/cli.py (`arb sim calibrate`), tests/test_calibrate.py,
docs/validation/calibration-grid.json, reports/ (HTML local, ignorado pelo git)
## Escopo
- Grid mínimo: `gate_3.min_sales` {1,2,3}, `gate_3.commission_cap_multiplier` {2,3,4},
  `gate_3.hard_cap_multiplier` {1.25,1.5,2.0}, `gate_1.kill_ctr_link` {0.006,0.008,0.010}.
  Regras variantes construídas em memória a partir de `Rules` (validadas), nunca gravadas.
- Para cada célula × perfil (`realistic`, `pessimistic`), 100 seeds: taxa de vencedor achado,
  borderline achado, vencedores mortos, waste médio, gasto médio até validar, gasto total.
- Saída JSON determinística + HTML local com tabela ordenável e fronteira de Pareto
  (acerto × waste). Destacar a célula atual de `rules.yaml`.
## Critérios de aceite
- Execução completa < 10 min local (paralelizar por processo se preciso; seeds fixas).
- JSON idêntico em duas execuções.
- `rules.yaml` intocado (teste verifica hash).
## Testes obrigatórios
Grid pequeno (2×2, 5 seeds) determinístico; variantes inválidas recusadas; arquivo de regras
inalterado após rodar.
