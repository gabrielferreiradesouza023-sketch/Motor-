# T-36: Escritor Meta restrito a pausa (sem uso real)
Fase: F6-pré  |  Depende de: T-35
## Objetivo
O freio de pânico hoje só pausa entidades simuladas; entidades reais ficam
`remote_pause_pending`. Pausar é a única escrita autônoma permitida pela constituição, então
deve ser a primeira escrita real a existir — testada só com transporte simulado.
## Arquivos
src/arb/meta/pause.py (novo), src/arb/launcher/actions.py, src/arb/launcher/panic.py,
tests/test_meta_pause.py, ops/decisions.md (ADR)
## Escopo
- Cliente que só sabe fazer `POST /{id}` com `status=PAUSED`; qualquer outro campo recusado.
- Passa por `safety.require_external_write("pause")`; com LIVE_MODE=false nunca constrói
  cliente real. Idempotente (pausar pausado = no-op), erro sanitizado (sem token).
- `panic` usa o escritor quando LIVE_MODE=true; em simulação, comportamento atual.
- Testes só com `httpx.MockTransport`. **Proibido** chamar a API real ou usar token real.
## Critérios de aceite
Payload exato verificado no mock; status diferente de PAUSED impossível de construir;
nenhuma rede real (teste falha se transporte real for instanciado).
## Testes obrigatórios
Pausa feliz, já pausado, erro 190 (token), 4xx/5xx sanitizados, panic com mix de entidades.

## Evidência de conclusão
PauseWriter aceita só POST numérico status=PAUSED; modo false não cria transporte e factory não lê credenciais. MockTransport verifica payload, idempotência, 190/4xx/5xx/redirect/transporte sanitizados. Panic misto registra intent antes do HTTP e resultado append-only, falha mantém remoto ativo. 89 testes focados; ADR-021, sem API real.
Gates: Ruff lint/format, pytest e arb doctor verdes. rules.yaml preservado.
