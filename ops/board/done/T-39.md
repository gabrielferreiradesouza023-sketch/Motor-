# T-39: Preflight read-only para o aceite real F5/F6
Fase: F5/F6-pré  |  Depende de: T-34, T-36
## Objetivo
Um comando que diz ao humano, antes do primeiro real, se todas as camadas de defesa existem.
## Arquivos
src/arb/preflight.py (novo), src/arb/cli.py (`arb preflight`), tests/test_preflight.py,
docs/validation/f5-f6-checklist.md
## Escopo
- Checagens (cada uma ok/aviso/erro com instrução de correção, nunca imprimir segredos):
  credenciais presentes (só nomes), `APPROVAL_SIGNING_KEY` presente, versão Graph definida,
  limite de gasto da conta Meta lido via API **somente leitura** e ≤ `total_cap_cents`,
  orçamento declarado do cartão (variável `CARD_LIMIT_CENTS`) ≤ `total_cap_cents`,
  backup do dia existe e restaura, scheduler com trava, alerta configurado (opcional),
  `panic` real disponível (T-36).
- Saída humana + `--json`. Exit 1 se qualquer erro.
- Testes com MockTransport e ambiente sintético. **Não chamar a API real.**
## Critérios de aceite
Cada checagem tem teste ok/erro; checklist em português para o humano executar no aceite real.
## Testes obrigatórios
Matriz de checagens; nenhuma saída contém valor de variável sensível.

## Evidência de conclusão
Preflight humano/JSON com exit 1 em erro, GET Meta só por opt-in e MockTransport nos testes. 37 casos de presença/cap/cartão/backup/trava/alerta/panic, valores sensíveis omitidos, HMAC nunca lido mesmo presente.
