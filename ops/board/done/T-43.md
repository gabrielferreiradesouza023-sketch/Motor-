# T-43: Reconciliação de pausas pendentes/incertas por leitura Meta
Fase: F6-pré  |  Depende de: T-42
## Objetivo
Fechar pendências do ledger comparando com o estado remoto lido por `Reader.ads()` (campo
`status` já consumido pelo código atual), sem nenhuma escrita remota.
## Arquivos
src/arb/reconcile.py (novo), src/arb/cli.py (`arb ops reconcile [--json]`), src/arb/meta/read.py
(somente se faltar um método de leitura por id; reutilizar `ads()` se suficiente),
tests/test_reconcile.py, scripts/check_coverage.py (incluir arb.reconcile)
## Escopo
- Para cada pendência de pausa: remoto `PAUSED` → append `pause_result` `reconciled_paused` e
  entidade local `paused`; remoto `ACTIVE` → `reconciled_not_paused` (libera nova tentativa);
  ausente/erro de leitura → mantém pendente e gera alerta. Append-only; nunca apaga Action.
- Valores de status remoto aceitos: apenas os já tratados no código (`ACTIVE`, `PAUSED`);
  qualquer outro → pendente + alerta ("status desconhecido"), sem inferir.
- Idempotente: rodar duas vezes não cria registros duplicados.
## Critérios de aceite
Matriz completa com MockTransport; leitura falha fecha nada; reconciliação repetida é no-op.
## Testes obrigatórios
PAUSED, ACTIVE, ausente, status desconhecido, 190/5xx de leitura, repetição, entidade já pausada
localmente; nenhuma requisição de escrita (AST/contador do transporte).
