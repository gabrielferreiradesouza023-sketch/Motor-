# T-66: Pacote de serviço para host persistente (sem instalar)
Fase: F8+  |  Depende de: T-59, T-65
## Objetivo
"Host persistente" é pendência humana. Entregar os arquivos e a verificação para o humano
instalar em Linux/WSL, sem que o agente instale ou inicie nada.
## Arquivos
deploy/systemd/*.service, deploy/systemd/*.timer (scheduler nos ciclos 09:00/18:00/23:30
America/Sao_Paulo, backup diário, drill diário), src/arb/service.py, src/arb/cli.py
(`arb service render --root <dir> --user <u>` e `arb service check`), docs/runbooks/host.md,
tests/test_service.py
## Escopo
- Render determinístico com caminhos absolutos, `LIVE_MODE=false` explícito, sem segredos nos
  arquivos (EnvironmentFile apontado, nunca conteúdo), hardening básico do systemd.
- `check` valida arquivos renderizados, horários vs `settings.cycles`, trava e permissões.
- Proibido executar `systemctl`, instalar ou habilitar timers.
## Critérios de aceite
Arquivos gerados batem com snapshot; horários convertidos corretamente (inclusive horário
de verão inexistente em São Paulo hoje — não presumir mudanças futuras).
## Testes obrigatórios
Render snapshot, check positivo/negativo, ausência de segredos, nenhum subprocess de systemctl.
