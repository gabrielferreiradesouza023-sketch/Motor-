# T-54: Ensaio completo `arb drill run` (simulação + FakeMeta)
Fase: F8+  |  Depende de: T-45, T-46, T-47, T-48, T-49, T-50, T-53
## Objetivo
Um comando que exercita a operação inteira e verifica invariantes, para servir de ensaio geral
antes de qualquer aceite real e de regressão no CI.
## Arquivos
src/arb/drill.py (novo), src/arb/cli.py (`arb drill run --seed N [--json]`), tests/test_drill.py,
docs/validation/drill-seed-*.json, .github/workflows/ci.yml (rodar 1 seed curta)
## Escopo
Fluxo: scout CSV → new_offer assinada (chave sintética de teste gerada em diretório temporário,
nunca versionada) → criativos aprovados → plano → launch → activate → ciclos com tráfego
simulado → kill → pausa → queda injetada → retomada → reconciliação → escala → backup →
restore em quarentena → release → relatório.
Invariantes: nenhuma exposição sem aprovação; nenhuma ação externa sem Action; nenhuma
duplicação; nenhuma entidade ativa após kill; quarentena respeitada; totais batem.
## Critérios de aceite
3 seeds determinísticas com JSON idêntico em 2 execuções; CI roda 1 seed em < 2 min.
## Testes obrigatórios
Drill verde; cada invariante tem um teste que planta a violação e confirma que o drill falha.
