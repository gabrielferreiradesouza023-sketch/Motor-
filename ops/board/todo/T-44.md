# T-44: Scheduler pausa entidades Meta pelo escritor de pausa
Fase: F6-pré  |  Depende de: T-42, T-43
## Objetivo
No estágio `actions`, entidades com `meta_id` hoje só geram o alerta `remote_pause_pending`,
mesmo em live. A constituição permite pausa autônoma; o freio do scheduler deve usar o mesmo
caminho auditado de `pause()`/`PauseWriter` que o panic usa.
## Arquivos
src/arb/scheduler/__init__.py (writer injetável em `run_cycle`), tests/test_scheduler_live_pause.py
## Escopo
- Simulação: comportamento atual inalterado (alerta). Live (somente em teste, via monkeypatch +
  MockTransport): kill/teto/stale/freio → `pause()` remoto, ordem campanha → conjunto → anúncio,
  sem repetir filhos de pai já pausado no mesmo ciclo.
- Pendência aberta no ledger (T-42) → não pausa, gera alerta "reconciliar".
- Falha de pausa de uma entidade não interrompe as demais; erro vai para o resultado do ciclo.
## Critérios de aceite
Um POST por entidade-alvo por ciclo; retomada do mesmo `scheduled_at` não repete POST.
## Testes obrigatórios
Simulação inalterada (snapshot do resultado atual), live com mock, pendência bloqueando,
falha parcial, retomada sem POST duplicado.
