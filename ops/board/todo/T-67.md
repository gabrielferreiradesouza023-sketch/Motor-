# T-67: Kit de aceite F5 somente leitura
Fase: F5  |  Depende de: T-65
## Objetivo
O aceite real F5 é do humano. Entregar um comando que ele roda no próprio host para produzir
evidência objetiva, usando apenas leituras que o `Reader` já implementa (account, insights, ads).
## Arquivos
src/arb/accept.py (novo), src/arb/cli.py (`arb accept f5 --out <arquivo>`),
docs/validation/f5-acceptance.md, tests/test_accept_f5.py
## Escopo
- Verifica: moeda BRL e fuso America/Sao_Paulo da conta, leitura de insights de uma janela
  curta, leitura de ads, `spend_cap` ≤ `total_cap_cents`. Nenhuma escrita.
- Evidência JSON redigida (sem token, sem ids completos: só sufixos), com versão Graph usada.
- No cloud dos agentes: testado somente com MockTransport; nunca executado contra a API real.
## Critérios de aceite
Cada verificação tem caso ok/erro; JSON sem segredos; exit 1 em qualquer erro.
## Testes obrigatórios
Matriz com MockTransport, redação, ausência de qualquer requisição de escrita.
