# T-71: Painel de prontidão para dinheiro real
Fase: F5/F6  |  Depende de: T-64, T-65, T-66, T-67, T-68, T-69, T-70
## Objetivo
Um único comando que diz, com base em evidências, o que ainda impede dinheiro real. Nunca
declara "pronto" sem todas as evidências humanas.
## Arquivos
src/arb/readiness.py, src/arb/cli.py (`arb readiness [--json]`), docs/validation/readiness.md,
tests/test_readiness.py, ops/HANDOFF.md
## Escopo
- Itens: preflight, drill recente, permissões, chave pública, evidências F5/F6/rastreio (arquivos
  dos kits com data e hash), V-01–V-06 marcados pelo humano em arquivo versionado próprio,
  executor Graph (sempre bloqueado neste batch), cartão/spend_cap, serviço verificado.
- Saída: lista ✔/✘ com motivo e próximo passo; exit 0 somente se tudo ✔ — o que é impossível
  enquanto o executor Graph não existir (teste garante).
## Critérios de aceite
Com o estado atual do repositório o resultado é "não pronto" com a lista correta de pendências.
## Testes obrigatórios
Cada item ok/erro; impossibilidade de "pronto" sem executor; JSON estável.
