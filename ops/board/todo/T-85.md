# T-85: Rotina diária da fumaça em um comando (`arb smoke daily`)
Fase: F8  |  Depende de: T-84
## Objetivo
Um comando que o humano roda 3x ao dia: lê a Meta, importa vendas (opcional), gera relatório
datado e diz com código de saída se é preciso pausar à mão.
## Arquivos
src/arb/smoke.py (ou src/arb/smoke_daily.py), src/arb/cli.py, src/arb/service.py (opcional
abaixo), tests/test_smoke_daily.py, docs/runbooks/piloto.md (link), ops/decisions.md (ADR-045)
## Escopo
- `arb smoke daily --campaign ID [--database] [--since AAAA-MM-DD] [--until AAAA-MM-DD]
  [--sales-csv CSV --mapping MAPA] [--output-dir reports/smoke] [--json]`.
  Padrões: `since` = data local de registro da fumaça; `until` = hoje no fuso configurado.
- Sequência, reaproveitando as funções de `sync meta`, `sales import` e `smoke report`:
  1. `require_simulation()` (igual a `sync meta`).
  2. Sync Meta da janela. Falha: exit 3, mensagem clara, **nenhum** relatório novo escrito,
     relatórios anteriores intactos.
  3. Se `--sales-csv`: importação idempotente com o mapeamento declarativo (V-01).
     Sem mapeamento validado, recusar; nunca inventar formato.
  4. Relatório em `<output-dir>/<AAAA-MM-DD>T<HHMM>.json` e `.md` (horário local), sem
     sobrescrever arquivo existente; recusar destino igual ao banco/config, symlink e hardlink
     (mesma proteção da T-83).
  5. Resumo no stdout: gasto bruto estimado, % do teto, CPM, CTR, hook, visitas à ponte,
     checkouts, vendas casadas/não casadas, frescor da última coleta.
- Alertas e exit code (o motor **nunca** pausa a fumaça, ADR-042):
  - <80% do teto: exit 0.
  - ≥80% (usar 0.8 como constante documentada no ADR, não editar rules.yaml): linha
    "ATENÇÃO: prepare-se para pausar", exit 0.
  - ≥100%: linha "PAUSE AGORA NO GERENCIADOR", exit 2.
  - Coleta mais velha que `controls.stale_after_hours`: aviso de dado atrasado.
- Opcional, se couber sem mexer na saída padrão: `arb service render --smoke-campaign ID`
  gera unidade oneshot + timer nos horários de `settings.cycles` chamando `smoke daily`
  com `LIVE_MODE=false`. Sem a flag, pacote renderizado byte-idêntico. Nunca instalar.
- ADR-045 (Proposto): limiar de 80%, códigos de saída, política de arquivos.
## Critérios de aceite
MockTransport com respostas GET fixas: relatório com números conferidos contra referência
calculada à mão (gasto bruto com imposto 0.13, CPM, CTR); 79,99% → exit 0 sem alerta, 80% →
alerta exit 0, 100% → exit 2; falha de rede → exit 3 sem arquivo novo; segunda execução na
mesma janela não duplica gasto nem vendas; zero escritas (nenhum POST/DELETE no transporte).
## Testes obrigatórios
Gates do BATCH-04 §4; módulo novo no gate de 95%.
